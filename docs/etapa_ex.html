Etapa EX

Execute: elige los operandos correctos con forwarding, calcula con la ALU, decide si la instrucción salta y adónde, y deja el resultado en el latch EX/MEM para el ciclo siguiente.

Las piezas clave en el Verilog

Forwarding (forwarding_unit.v)

ex_mem_ok = ex_mem_reg_write && ex_mem_rd != 0;
mem_wb_ok = mem_wb_reg_write && mem_wb_rd != 0;
forward_a =
  (ex_mem_ok && ex_mem_rd == rs1) ? 2'b10 :
  (mem_wb_ok && mem_wb_rd == rs1) ? 2'b01 :
                                    2'b00;

Control de ALU (alu_control.v)

case (alu_op)
  00: ADD;                // ld, st, jalr, lui
  01: SUB;                // beq, bne
  10: {bit30, funct3};    // tipo R
  11: {(funct3==101) & bit30,
       funct3};           // tipo I
endcase

Decisión de salto (ex_stage.v)

cond   = (funct3 == BNE) ? ~zero : zero;
taken  = (branch & cond) | jal | jalr;
target = jalr ? (alu_result & ~1)
              : pc + imm;

Resultado y dato del store (ex_stage.v)

result = (jal | jalr) ? pc4 : alu_result;
if (reset)   EX/MEM <= 0;
else if (en) EX/MEM <= {result, b_fwd, ...};
// b_fwd y no rs2_data: el dato del sw
// tambien puede venir de adelante

Decisión 1-A: el multiplexor de PC+4 de jal/jalr está en EX y no en WB. Así lo que hay en EX/MEM es siempre "lo que se va a escribir en rd" (salvo en los loads, donde es la dirección), el forwarding toma una sola fuente sin casos especiales y EX/MEM no necesita llevar los 32 bits de PC+4.

Preguntas para la defensa

  1. ¿Por qué EX/MEM tiene prioridad sobre MEM/WB en el forwarding?Si las dos instrucciones de adelante escriben el mismo registro, la de EX/MEM es la más nueva y es la que vale en el orden del programa.
  2. ¿Por qué se compara rd con 0?x0 vale siempre 0. Si una instrucción "escribe" x0, ese valor no existe y no se puede forwardear.
  3. ¿Y la distancia 3, cuando la productora está en WB y la consumidora en ID?No pasa por el forwarding: la resuelve el bypass del banco de registros, que entrega el dato que WB está escribiendo.
  4. ¿Por qué el forwarding va antes del mux ALUSrcB?Porque el dato a guardar de un store (rs2) también puede depender de una instrucción de adelante, aunque la ALU use el inmediato para la dirección.
  5. ¿Por qué addi con inmediato negativo no se convierte en sub?En tipo I el bit 30 es parte del inmediato. El control de la ALU solo lo usa cuando funct3 = 101 (srli/srai), donde es funct7.
  6. ¿Cuánto cuesta un salto tomado?Dos ciclos: se resuelve en EX y se descartan las dos instrucciones que entraron detrás (IF/ID e ID/EX). Moverlo a ID lo baja a uno.
  7. ¿Por qué jalr pone el bit 0 en 0?Lo pide la especificación de RISC-V, para que el destino sea siempre una dirección par aunque rs1 + imm sea impar.
  8. ¿Cuál es el camino crítico?EX/MEM → forwarding → ALU → zero → decisión → PC: cruza toda la etapa y vuelve a IF en el mismo ciclo. Es el candidato a limitar la frecuencia máxima.
